## 🚀 Öne çıkan işler

**🌐 [metinoz.tr](https://www.metinoz.tr)** — Kişisel platform
Next.js 16 + TypeScript. Blog, portföy, mini uygulamalar (piyano, tuner, ramazan sayacı) ve sipariş/checkout akışı olan mağaza modülü. Admin paneli, NextAuth ile korunan API katmanı, n8n ile otomatik blog üretimi. Docker imajı + VPS üzerinde tek komutla güncelleme.

**🏢 Site & Apartman Yönetim Sistemi** — *private*
Next.js + Prisma + PostgreSQL. Blok/daire/sakin yönetimi, aidat ve borç takibi, tahsilat, gider girişi, cari hesaplar, PDF raporlama, işlem logları ve geri alma (undo), davet akışı, docx teklif şablonu üretimi.

**🏠 Home Lab** — *private*
Raspberry Pi 5 + 480 GB SSD üzerinde Docker Compose yığını: Nextcloud, n8n, Vaultwarden, AdGuard Home, Coolify. Cloudflare Tunnel ile dışarıya açık, Wake-on-LAN ile uzaktan yönetim.
